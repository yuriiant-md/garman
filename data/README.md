# Дані

Синтетичні тексти створюються з еталонної угоди `Deal`, яку будує Python. Модель в Ollama переписує її умови в «брудне» повідомлення трейдера, а скрипт перевіряє, що кожне заповнене значення стоїть у тексті поруч зі словами свого поля.

## Як згенерувати

```bash
ollama pull llama3.1:8b
uv run python -m scripts.generate_synthetic --model llama3.1:8b
```

**Модель-генератор не може бути з родин, які ми порівнюємо:** Lapa (зроблена на Gemma 3), Gemma, Qwen. Інакше dev-набір написаний «рідним» стилем однієї з моделей і дає їй фору. Скрипт відхиляє такі назви. Назва моделі записується в кожен JSON (поле `model`).

## Що робить скрипт

1. **Угода.** Python будує `Deal` для пшениці в реалістичних межах: ціна 8 300–9 700 грн/т; неустойку платить сторона, що порушила умову (за прострочення оплати — покупець, за поставку — продавець); пеня за прострочення оплати — у % за день або в розмірі облікової ставки НБУ (одинарної чи подвійної); протеїн залежить від класу. Частину полів навмисно лишає `null`. Значень `other` у синтетиці немає: їх неможливо однозначно перевірити в тексті.
2. **Брудність** задається чотирма незалежними параметрами й записується в JSON (поле `dirtiness`): довжина (рядок у Viber … лист на 1–2 сторінки), мова (українська, з російською, з англійськими термінами), друкарські помилки (немає, 1–2, 3–5), месенджерні скорочення (так чи ні).
3. **Текст.** Умови передаються моделі українською (не JSON), і модель переписує їх своїми словами.
4. **Перевірка** (`scripts/synthetic_checks.py`). Значення зараховується, лише якщо стоїть поруч зі словами свого поля: «5» у «толеранс 5%» не підтверджує строк оплати, а «0,1%» не підтверджує пеню за поставку, якщо стоїть біля прострочення оплати. Не знайдено — нова спроба з переліком пропущених умов, до трьох спроб.
5. **Невдала угода** пропускається, замість неї береться наступний seed. Кожен текст записується одразу, тож збій посеред прогону не губить уже готові тексти.

## Що де лежить

- `data/texts/synthetic_NNN.txt` — 20 текстів dev-набору;
- `data/synthetic/synthetic_NNN.json` — еталонний `Deal`, модель, seed, кількість спроб і параметри брудності;
- `data/synthetic/prompt_examples/` — 3 тексти поза набором, приклади для промпту v2.

Перед використанням вручну переглянь щонайменше 5 текстів: перевірка ловить пропущені значення і значення не на своєму місці, але не бачить зайвих умов, які модель могла додати сама.
