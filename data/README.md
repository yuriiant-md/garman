# Дані

Синтетичні тексти створюються з еталонної угоди `Deal`, згенерованої Python. Ollama переформульовує її в повідомлення трейдера; скрипт перевіряє наявність заповнених значень і за потреби просить модель виправити текст (до трьох спроб).

Для генерації потрібні встановлений Ollama і завантажена модель:

```bash
ollama list
uv run python -m scripts.generate_synthetic --model <назва-моделі>
```

За замовчуванням скрипт створює 20 текстів для dev-набору в `data/texts/` та 3 окремі приклади поза набором у `data/synthetic/prompt_examples/`. Для кожного тексту відповідний JSON з еталонним `Deal`, назвою моделі та кількістю спроб записується в `data/synthetic/`. Модель зазначається в метаданих кожного запису.

Перед використанням вручну переглянь щонайменше 5 текстів: автоматична перевірка знаходить відсутні еталонні значення, але не виявляє кожну додаткову чи двозначну умову.
