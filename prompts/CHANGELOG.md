# Журнал промптів

Кожна версія — окремий файл `extract_vN.md` з версією й датою в шапці. Описи полів (`Field(description=...)` у `src/schemas/deal.py`) однакові для всіх версій: усе, що змінюється між версіями, — лише в цих файлах.

## v1 — 18.10.2026, англійською з 20.10.2026

Чесний мінімальний baseline (`extract_v1.md`).

20.10 текст перекладено англійською без зміни змісту, щоб v1 і v2 відрізнялись лише змістом, а не мовою. Тоді ж англійськими стали спільні для всіх версій обгортка документа (`src/extraction/messages.py`) і мітка схеми для Ollama (`src/extraction/ollama_extractor.py`). Результати v1 перепрогнано; українська версія й її результати — в історії git до коміту з v2. Переклад майже не змінив цифр (точність заповнених на dev: Haiku 92.1 → 91.5%, Lapa 77.8 → 79.1%, у межах 95% ДІ), тож мова промпту сама по собі не головне.

- Роль: витягнути умови угоди про зерно з «брудного» тексту в JSON за схемою `Deal`.
- Правило «немає в тексті → null, не вгадуй», щоб модель не вигадувала значень.
- Правило «умова є, але не з переліку → other».
- Без прикладів і без пояснень окремих полів: що означає поле, модель бачить з опису в схемі.

Мета — точка відліку, з якою порівнюватиметься v2.

## v2 — 20.10.2026

Промпт із правилами по полях (`extract_v2.md`), англійською.

**Звідки зміни.** Помилки v1 на dev (`synthetic_001–020`, обидві моделі) і правила розмітки з `data/golden/RULES.md` — та сама специфікація полів, за якою розмічено еталон. На test (`prozorro_*`, `own_*`) моделі ще не проганялись, тож помилок test у v2 немає; прикладів із test-текстів у промпті теж немає (числа в прикладах інші). Два раунди на dev: після першого прогону v2 додано правила «немає умови оплати → `payment: null`», розшифровку к.д./б.д., «фураж — це клас», «клас ≠ культура», «толеранс не названо → null», «не обирати базис, якого немає в тексті».

**Що лишилось на dev:**

- Lapa: дата без року — 15 полів (`null` або 2023), правило з `{today}` вона виконує погано; вигадані умови оплати (5 полів), транслітерація (2), вигадана неустойка (007).
- Haiku: «с доставкой в Одесу» (008, 009) → `basis: other`. За `RULES.md` це правильно (умова поставки без терміна), а синтетичний еталон каже `null` — розбіжність еталонів, не моделі. Ще 012: дату пораховано з відносного строку, хоча промпт велить лишити `period_raw`; 007: культура з класу.
